# Copywriting & Writing Skill

- Establish purpose, audience, channel, desired action, voice, length, constraints, and factual claims.
- Reuse the user's confirmed voice preferences. Don't invent testimonials, capabilities, discounts, credentials, outcomes, testimonials, or product claims.
- Produce one strong default draft first. Add variants only when they materially help.
- For sensitive or consequential claims, flag items that need verification.
- Keep the user's meaning and avoid generic AI marketing clichés, excess adjectives, false urgency, and inflated promises.
- If a distinct copywriter agent would be called, ask permission first via the router; this skill alone is not a separate agent.
