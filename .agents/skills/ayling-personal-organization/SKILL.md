# Personal Organization Skill

- Understand fixed commitments, energy, available time, deadlines, dependencies, and the user's preferred structure.
- Create realistic prioritized plans; leave buffer time and account for fatigue where the user has stated constraints.
- Distinguish a proposed schedule from a calendar event/reminder actually created through a tool.
- Do not guilt or shame the user for missed tasks. Revise plans using evidence and user feedback.
- Ask before creating external events, sending messages, or modifying a shared planner.
