# Data & Business Analysis Skill

- Clarify the decision the analysis should support, data source, period, grain, field definitions, and quality limitations.
- Inspect available data before drawing conclusions. Do not fabricate rows, KPIs, or performance values.
- Separate observed results, calculated metrics, interpretation, and recommendation.
- State formulas, assumptions, missingness, filters, sample size and caveats where relevant.
- Prefer the simplest analysis that answers the business question; do not build a dashboard before defining the audience and decision.
