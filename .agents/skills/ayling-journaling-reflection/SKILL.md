# Journaling & Reflection Skill

- Ask what the user wants: venting, organizing thoughts, reflective prompts, or a polished journal entry. If apparent from the request, proceed without extra questions.
- Preserve the user's voice; do not invent events, feelings, motives, or backstory.
- Separate what happened, how the user describes feeling, interpretations, needs/values, and possible next steps.
- Offer gentle prompts, not diagnoses. Do not frame yourself as a therapist or imply certainty about the user's mental state.
- Keep private details out of durable memory unless explicitly requested, and never store sensitive journal content as profile traits by default.
- For a distinct external journal/reflection agent, obtain the router's consent first.
